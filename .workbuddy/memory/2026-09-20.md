# 2026-09-20

## 新增：检测更新后一键下载并静默覆盖安装

- `src/EmbyPlayer/Services/UpdateService.cs`
  - `UpdateInfo` 新增 `InstallerAssetName / InstallerUrl / InstallerSize / HasInstaller`；新增 `DownloadProgress` record。
  - `CheckForUpdateAsync` 解析 Release 的 `assets`，按 `-{SC|FD}-` 匹配安装包；变体由 `AppContext.BaseDirectory` 是否存在 `coreclr.dll/hostfxr.dll/System.Private.CoreLib.dll` 判定（`CurrentVariant`）。
  - 新增 `DownloadInstallerAsync`（流式下载 + IProgress，先写 `.part` 再 Move，下载前清理旧 exe）、`LaunchInstaller`（`/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /NOCANCEL /SP- /CLOSEAPPLICATIONS /LOG=...`，装到 Program Files 时加 `Verb=runas` 提权）。
- `src/EmbyPlayer/MainWindow.xaml.cs`
  - `ShowUpdateDialogAsync` 改为「立即更新」按钮；用 `PrimaryButtonClick` + `GetDeferral()` + `args.Cancel = true` 保持弹窗，弹窗内显示进度条；成功后调用 `App.ExitForUpdate()`。
  - 注意坑：lambda 参数名 `_` 会与 `_ = RunAutoUpdateAsync(...)` 的弃元冲突（编译报错 CS0029），lambda 参数要改名（用 `sender`）。
- `src/EmbyPlayer/App.xaml.cs`：新增 `ExitForUpdate()`（保存设置 → `MpvController.Dispose()` 停 mpv → `Environment.Exit(0)`；WinUI3 的 `Application.Exit` 不保证进程立即退出，会锁住待覆盖文件）。
- `installer/EmbyPlayer.iss`
  - `[Setup]` 加 `UsePreviousAppDir/Tasks/Language=yes`、`CloseApplications=yes`（保证静默安装沿用原目录覆盖）。
  - `[Run]` 增一条 `Check: IsSilentInstall`（`WizardSilent()`）的启动项：静默安装后自动重启应用（原 `postinstall skipifsilent` 那条在静默模式会被跳过）。
- `README.md`：补充「自动更新」小节。

验证：`dotnet build -c Release -p:Platform=x64` 0 错误；用 ISCC `/DFD` 编译安装包脚本通过（临时建的 `dist/publish-fd` 已删除）。
